KickSide provides a runnable application and independently installable Lua modules on [Wippy](https://wippy.ai). The application includes agent chat, knowledge, typed records, workspace tools, and durable automations.

[Website](https://kickside.ai) · [Documentation](https://github.com/kicksideai/docs) · [Get started](https://github.com/kicksideai/docs/blob/main/getting-started/index.md)

![The KickSide application hosts a Chestor graph with fictional demonstration data](https://raw.githubusercontent.com/kicksideai/docs/main/using/assets/chestor/graph.png)

| Repository | What it provides |
| --- | --- |
| [kickside](https://github.com/kicksideai/kickside) | The application, core services and platform modules. |
| [crm](https://github.com/kicksideai/crm) | Typed records, relations, schemas and business views. |
| [components](https://github.com/kicksideai/components) | Dashboard, research, first-agent onboarding and SSO modules. |
| [chestor](https://github.com/kicksideai/chestor) | Workspace trees, semantic graphs, journals, roadmaps and schema diagrams. |
| [providers](https://github.com/kicksideai/providers) | Service connectors, knowledge engines, upload processing and agent tools. |
| [converters](https://github.com/kicksideai/converters) | WebAssembly document converters with Lua SDKs. |
| [module](https://github.com/kicksideai/module) | A template for an independently installable module. |
| [docs](https://github.com/kicksideai/docs) | Product guides and public module documentation. |
| [.github](https://github.com/kicksideai/.github) | Contribution, support and community resources. |
