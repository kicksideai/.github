# Support

## Documentation and setup

Start with the affected repository's README and its build/test instructions.
The [KickSide quick start](https://github.com/kicksideai/kickside#quick-start),
[developer handbook](https://hub.wippy.ai/kickside/kickside/wiki/docs/kickside-development/developer-handbook.md), and [Wippy documentation](https://wippy.ai)
cover application setup, contracts, and runtime behavior.
Find current CLI releases and published modules on [Wippy Hub](https://hub.wippy.ai).

## Questions and feature ideas

Use [KickSide Discussions](https://github.com/kicksideai/kickside/discussions)
for usage questions, design discussions, and help choosing modules. For a
reproducible defect or a specific feature request, open an issue in the affected
repository using its issue forms. Include versions, expected and actual behavior,
and a minimal reproduction with redacted logs.

## Private matters

Report vulnerabilities under [SECURITY.md](SECURITY.md). For licensing,
commercial-license enquiries, CLA questions, or matters that cannot be discussed
publicly, email [licensing@wippy.ai](mailto:licensing@wippy.ai).
Report community conduct concerns using [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Community support does not imply a guaranteed response time or support contract.
